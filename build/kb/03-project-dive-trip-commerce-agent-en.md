Document language: English
Version: 2 (2026-10-02)
Source cutoff: 2026-10-02
Scope: The voice shopping agent Santiago Llaguno built for a dive-trip operator, described at a technical level. The agent is built on public trip data.

## What is the dive-trip agent? A shopping agent for dive travel
Santiago Llaguno built a voice shopping agent for a dive-trip operator. The dive-trip agent helps a traveler choose and book a diving adventure. Santiago built it on public trip data.
Source: ledger P1

## How does the dive-trip agent recommend a trip? Based on the traveler's profile
The dive-trip agent that Santiago Llaguno built recommends adventures based on each traveler's profile. The dive-trip agent takes into account details such as whether the traveler is coming with family and what diving certification the traveler holds.
Source: ledger P1

## Does the dive-trip agent teach anything? Species and requirements
The dive-trip agent that Santiago Llaguno built also educates the traveler. It explains the marine species a traveler can expect to see on each trip and the requirements a traveler has to meet to join it.
Source: ledger P1

## How does the dive-trip agent handle availability? Live lookups
The dive-trip agent that Santiago Llaguno built checks trip availability live instead of guessing. A wrong answer about open spots is the kind of error the dive-trip agent is built to avoid.
Source: ledger P1

## When does the dive-trip agent hand off to a person? Health and risk
When a traveler raises a health or risk topic, the dive-trip agent that Santiago Llaguno built passes the conversation to a human on the operator's concierge team.
Source: ledger P1

## How did Santiago test the dive-trip agent? Seven eval blocks
Santiago Llaguno grouped the evals for the dive-trip agent into seven blocks, labeled A through G. The seven blocks cover routing to a human, the booking tools, availability checks and the accuracy of the agent's answers.
Source: ledger P1

## What matters most in the dive-trip agent? Safety and availability
For the dive-trip agent, Santiago Llaguno treated two areas as the most critical. The first is safety: the dive-trip agent has to route health and risk topics to a person. The second is availability: a hallucinated answer about open spots costs the operator money.
Source: ledger P1

## What was the dive-trip agent based on? Anthropic's shopping agent blueprint
Santiago Llaguno based the design of the dive-trip agent on Anthropic's shopping agent blueprint.
Source: ledger P1
