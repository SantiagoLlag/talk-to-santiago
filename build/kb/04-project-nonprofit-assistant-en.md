# Talk to Santiago · [EN] Project: the nonprofit voice assistant and its platforms
Document language: English
Version: 1 (2026-09-25)
Source cutoff: 2026-09-25
Scope: The website voice assistant, the events platform and the financial review platform that Santiago Llaguno built for a nonprofit in Chiapas, Mexico, described at a technical level.

## What is the nonprofit assistant? A voice assistant for a website in Chiapas
Santiago Llaguno built a voice assistant for the website of a nonprofit in Chiapas, Mexico. The nonprofit works alongside Tseltal Indigenous communities. The nonprofit assistant talks with visitors to the organization's website.
Source: ledger P2

## What does the nonprofit assistant do for visitors? Guidance and donations
The nonprofit assistant that Santiago Llaguno built answers visitors' questions using only public information. The nonprofit assistant uses navigation tools to guide each visitor through the website, and it moves the visitor closer to making a donation.
Source: ledger P2

## How did Santiago protect privacy in the nonprofit assistant? A curated knowledge base
In the nonprofit assistant, Santiago Llaguno's privacy control was the knowledge base itself. Santiago curated the knowledge base so that it never contained any of the organization's internal information. The nonprofit assistant can only draw on public content.
Source: ledger P2

## How was the nonprofit assistant tested? A 45-case golden set
Santiago Llaguno tested the nonprofit assistant against a golden set of 45 cases. The 45 cases in the nonprofit assistant's golden set cover knowledge of the communities, donations, the organization's projects and its philosophy.
Source: ledger P2

## Is the nonprofit assistant live? On a test copy of the site
As of September 2026, the nonprofit assistant that Santiago Llaguno built runs on a test copy of the organization's website. The launch of the nonprofit assistant on the real website is still pending.
Source: ledger P2

## What else did Santiago build for the nonprofit? An events platform
For the same nonprofit in Chiapas, Santiago Llaguno built an events platform. The events platform handles invitations with QR codes and guest registration. The events platform also reads payment receipts automatically.
Source: ledger P3

## What else did Santiago build for the nonprofit? A financial review platform
For the same nonprofit in Chiapas, Santiago Llaguno built a platform that cross-checks the organization's financial files. The financial review platform flags inconsistencies between the files. Users of the platform can then talk with the AI about each inconsistency the platform flags.
Source: ledger P3
